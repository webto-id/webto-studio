# Prompt gallery

Requests you can paste into your agent after `npm install` and setting the
token. Replace what is in angle brackets. The agent will interview you before
it builds anything, so a short request is enough.

## A client's site from a brief

```
Build a website for my client <business name>, a <kind of business> in <city>.
I have their brief and price list in <folder or file>.
```

```
Buatkan website untuk klien saya, <nama usaha>, <jenis usaha> di <kota>.
Catatan dari klien ada di <berkas>.
```

## Move an existing site

```
My client's current site is <url>. Move it to a new design and keep all of
its content. They own the photos of their premises and team.
```

```
Website lama klien saya ada di <url>. Buat ulang dengan desain baru tanpa
menghilangkan isinya.
```

## A template to sell

```
Make a template for <kind of business> to sell on the marketplace.
I want it to feel <two or three words>.
```

```
Buat template untuk <jenis usaha> yang akan saya jual di marketplace.
```

## A 3D landing page

```
A landing page for <product>. I have a 3D model of it in <file.glb> and I
want it to turn as the visitor scrolls.
```

```
Landing page untuk <produk>. Saya punya foto produknya; saya ingin ada kesan
kedalaman saat digulir.
```

## Changing a site that already exists

```
On <site name>, change the opening hours to <hours> and add a page for <topic>.
```

The agent exports the current site first, so edits made in the dashboard are
kept.
